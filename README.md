# Task 29 - Interactive Resume Builder

## Project Overview

The Interactive Resume Builder is a web-based application that allows users to create a professional resume using a simple form.

As the user enters information, the resume preview updates automatically in real time.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Personal information form
- Professional summary
- Skills section
- Dynamic education entries
- Dynamic experience entries
- Add and remove education records
- Add and remove experience records
- Real-time resume preview
- Responsive design
- Print-friendly resume
- Save resume as PDF using browser print functionality
